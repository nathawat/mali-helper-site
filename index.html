Mali helper

A private desktop tool for the “งานวัดมะลิ” (Mali Temple Fair) TikTok account.
เครื่องมือส่วนตัวสำหรับดูแลบัญชี TikTok “งานวัดมะลิ”

What it does

  • Shows the account's follower count over time and its own videos' views, likes, comments and shares, using TikTok Login Kit and Display API (read only).
  • Helps the operator prepare draft replies, comments and captions with AI. A person copies and posts every draft by hand.
  • It never posts, follows, likes or comments automatically.

The app runs on the operator's own computer and is not offered to the public.

ทำอะไรได้

  • ดูยอดผู้ติดตามรายวัน และยอดวิว ไลก์ คอมเมนต์ แชร์ของคลิปในบัญชี ผ่าน Login Kit และ Display API ของ TikTok แบบอ่านอย่างเดียว
  • ช่วยเตรียมร่างคำตอบ คอมเมนต์ และแคปชันด้วย AI โดยคนเป็นผู้คัดลอกไปโพสต์เองทุกครั้ง
  • ไม่โพสต์ ไม่กดติดตาม ไม่กดไลก์ และไม่คอมเมนต์แทนคน

แอปรันบนคอมพิวเตอร์ของผู้ดูแลเอง ไม่ได้เปิดให้บุคคลทั่วไปใช้
